# Odin Recipes

A beginner HTML Foundations project for ITE 10.

## Pages
- `index.html` — homepage, recipe navigation, comparison table, video player, and feedback form.
- `recipes/adobo.html` — Chicken Adobo.
- `recipes/sinigang.html` — Pork Sinigang.
- `recipes/pancit.html` — Pancit Canton.

## Run locally
Open `index.html` in a web browser.

## Multimedia
The homepage includes an HTML5 video player. To use it, add your own permitted MP4 cooking demonstration at `media/recipe-demo.mp4`.

## Notes
The feedback form is front-end only; it does not store or transmit submissions. Recipe quantities and times are starting estimates. Adjust to your ingredients, equipment, and food-safety requirements.
